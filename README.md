# IT Security & Compliance Audit Dashboard

An interactive Power BI dashboard that simulates an internal IT security audit — joining server logs, vulnerability/patch data, and employee training records into a single model to surface a composite risk score by department.

### Data

- **Network_Server_Logs.csv** — login events per server, with anomaly flags
- **Device_Vulnerability_Patches.csv** — CVE-style vulnerability records per server, with severity and patch status
- **HR_Employee_Training_Records.csv** — security training assignments and completion status per employee
